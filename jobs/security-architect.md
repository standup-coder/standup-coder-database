# 安全架构师职位描述(JD)

## 岗位基本信息
- **岗位名称**：安全架构师(Security Architect)
- **工作性质**：全职
- **工作地点**：北京/上海/深圳/杭州/成都
- **招聘人数**：若干
- **薪资范围**：40K-80K/月(根据经验水平)

## 岗位职责

### 企业安全架构设计
- 主导企业整体安全架构规划，落地零信任(Zero Trust)安全体系
- 设计并实施SASE(Secure Access Service Edge)安全接入架构
- 构建覆盖网络、终端、身份、数据的全栈安全防护体系
- 制定安全架构演进路线图，推动安全能力持续升级
- 设计混合云/多云环境下的统一安全架构方案

### 威胁建模与风险评估
- 对企业核心系统进行威胁建模(STRIDE/ATT&CK框架)
- 识别和评估系统架构中的安全风险和攻击面
- 制定风险缓解策略和安全加固方案
- 建立持续威胁检测和响应机制
- 组织红蓝对抗演练，验证安全架构有效性

### 安全合规体系建设
- 主导等保2.0(三级/四级)合规建设和测评
- 推动ISO 27001/ISO 27701信息安全管理体系认证
- 设计满足GDPR/《数据安全法》/《个人信息保护法》的数据合规方案
- 建立安全审计和合规检查常态化机制
- 对接监管机构和第三方审计，确保合规持续达标

### 云安全与数据安全治理
- 设计云原生安全架构(CWPP/CSPM/CASB)
- 制定数据分类分级策略和数据全生命周期安全方案
- 构建数据防泄漏(DLP)和数据脱敏体系
- 设计密钥管理和加密体系(传输加密/存储加密/字段级加密)
- 建立数据安全治理组织和流程规范

### 安全开发与应急响应
- 推动SDL(安全开发生命周期)在研发流程中落地
- 建设DevSecOps流水线，实现安全左移
- 制定安全编码规范和代码审计标准
- 建立安全事件应急响应体系(SOC/SIEM/SOAR)
- 组织安全事件复盘，持续完善应急预案

## 任职要求

### 必备技能
**安全架构能力**：
- 精通零信任架构设计(身份验证/微分段/最小权限)
- 熟悉主流云安全方案(AWS Security/Azure Sentinel/阿里云安全中心)
- 掌握企业级网络安全架构设计(防火墙/IDS/IPS/WAF)
- 具备大规模安全体系规划和落地经验
- 熟悉SASE/SSE架构和SD-WAN安全接入

**攻防技术能力**：
- 具备渗透测试和漏洞分析能力(OWASP Top 10)
- 熟悉常见攻击手法和防御策略(SQL注入/XSS/APT)
- 掌握密码学基础(对称/非对称加密/数字签名/PKI)
- 了解逆向工程和恶意代码分析
- 具备安全事件溯源和取证分析能力

**安全运营能力**：
- 熟悉SIEM平台(Splunk/ELK/阿里云SIEM)部署和规则编写
- 掌握SOAR自动化响应编排(Swimlane/XSOAR)
- 具备安全合规体系建设经验(等保/ISO27001/SOC2)
- 熟悉SDL和DevSecOps工具链(SAST/DAST/SCA)
- 具备安全团队管理和跨部门协调能力

### 经验要求
- **学历要求**：本科及以上学历，信息安全/计算机相关专业
- **工作经验**：
  - 中级岗位：5-8年安全领域工作经验
  - 高级岗位：8-12年安全架构设计经验
  - 资深岗位：12年以上安全体系建设经验
- **项目经验**：主导过大型企业安全架构设计或等保合规项目

### 加分技能
- 持有CISSP/CISM/SABSA/OSCP等安全认证
- 有金融/政企/医疗行业安全合规经验
- 具备安全产品研发经验(防火墙/EDR/SIEM)
- 有安全开源项目贡献或CVE漏洞发现记录
- 熟悉AI安全和大模型安全评估

4. **应急响应**：发现APT攻击后如何组织应急响应？溯源分析的关键步骤是什么？
