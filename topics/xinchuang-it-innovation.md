# 信创产业企业清单

## 主题介绍

信创（信息技术应用创新）是中国实现核心技术自主可控的国家战略。在中美科技博弈持续升级的背景下，中国加速推进IT基础设施的国产化替代进程。

### 产业背景

- **中美科技博弈**：2018年以来，美国对华实施多轮芯片出口管制和技术封锁，倒逼中国加速构建自主可控的IT产业链
- **党政军先行**：信创产业最早在党政机关和军工领域试点，2020年起进入规模化采购阶段
- **八大行业推进**：2022年后信创向金融、电信、教育、医疗、交通、能源、航天、烟草等关键行业全面渗透
- **市场规模**：预计2025-2027年信创产业总规模将突破2万亿元人民币

## 按行业应用分类

### 党政信创
- 最早启动（2014年试点），2020年规模化推广
- 核心需求：公文处理、OA系统、邮件系统、电子签章
- 典型方案：飞腾/鲲鹏 + 麒麟/统信 + 达梦/金仓 + WPS + 东方通

### 金融信创
- 2021年起加速，银行核心系统替换是重点
- 核心需求：核心交易系统、风控系统、数据仓库
- 典型方案：海光/鲲鹏 + 麒麟 + OceanBase/GaussDB + 东方通

### 电信信创
- 三大运营商2022年启动大规模集采
- 核心需求：BSS/OSS系统、计费系统、网络管理
- 典型方案：鲲鹏/海光 + 麒麟 + TiDB/OceanBase + 宝兰德

### 教育信创
- 高校和K12教育信息化国产化
- 核心需求：教学管理系统、科研计算、智慧校园
- 典型方案：飞腾/兆芯 + 统信UOS + 达梦 + WPS

### 医疗信创
- 医院信息系统（HIS）国产化替代
- 核心需求：HIS/LIS/PACS系统、电子病历
- 典型方案：鲲鹏/海光 + 麒麟 + 达梦/金仓 + 东方通

### 交通信创
- 铁路、公路、航空信息系统国产化
- 核心需求：调度系统、票务系统、信号控制
- 典型方案：飞腾/龙芯 + 麒麟 + 达梦 + 中创中间件

### 能源信创
- 电力、石油、天然气生产控制系统国产化
- 核心需求：SCADA系统、DCS系统、ERP
- 典型方案：鲲鹏/海光 + 麒麟 + GaussDB + 东方通

### 航天信创
- 航天器控制系统、地面站系统完全自主化
- 核心需求：嵌入式实时系统、仿真系统、遥测遥控
- 典型方案：龙芯/申威 + 麒麟/自研RTOS + 达梦

## 产业发展趋势

1. **从可用到好用**：信创产品正从"能用"向"好用"过渡，用户体验持续改善
2. **AI赋能信创**：大模型与信创结合，推动智能办公、智能运维等场景落地
3. **全栈协同**：从单点替代走向全栈适配，芯片-OS-数据库-应用一体化方案成为主流
4. **行业深化**：从党政向金融、电信等核心业务系统深入，替代难度和含金量同步提升
5. **生态繁荣**：信创适配认证产品数量快速增长，开源社区贡献度提升
