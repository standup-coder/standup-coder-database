# AI数据标注与RLHF外包产业清单

## 概述

AI训练数据产业是大模型时代的基础设施。从早期的图像分类标注，到如今的RLHF（基于人类反馈的强化学习）和SFT（监督微调），数据标注已从简单劳动密集型升级为需要专业知识的认知工作。全球AI训练数据市场规模预计在2026年超过150亿美元，中国占据约30%份额。

### 产业演进路径

```
传统标注(2012-2018) → 智能标注(2018-2022) → RLHF/SFT(2022-至今)
图像框选/语义分割      预标注+人工修正        人类偏好对齐/代码评估/推理验证
低技能/低单价          中技能/中单价          高技能/高单价
```

## 垂直领域标注

### 医疗数据标注

- **需求**：医学影像(CT/MRI/X光)分割、电子病历NER、医学问答
- **要求**：标注员需医学背景（执业医师/医学生）
- **代表公司**：Medidata、数坤科技、推想医疗内部团队
- **单价**：普通标注的5-20倍

### 法律数据标注

- **需求**：合同条款提取、判例分类、法律问答对构建
- **要求**：法学背景，律师/法学生优先
- **代表公司**：幂律智能、法智易
- **趋势**：大模型法律对齐需求激增

### 金融数据标注

- **需求**：财报解析、风控模型训练、智能客服对话
- **要求**：金融从业背景，CFA/CPA优先
- **代表公司**：恒生电子、同花顺内部团队

### 代码标注/评估

- **需求**：代码生成评估、Bug修复标注、代码审查偏好
- **要求**：软件工程师背景，算法能力
- **代表公司**：Outlier AI、Scale AI代码团队
- **趋势**：2024年后需求爆发，单价最高

### 多语言标注

- **需求**：翻译质量评估、多语言对齐、文化适配
- **要求**：双语/多语能力，文化理解
- **代表公司**：Appen、Lionbridge、海天瑞声
- **语种**：中英日韩为主，小语种溢价高

## 从业者指南

### 如何入行

1. **基础标注**：注册众包平台（百度众测/腾讯搜活帮），完成新手任务
2. **技能提升**：学习标注工具（LabelImg/CVAT/Prodigy），理解AI训练流程
3. **专业方向**：选择垂直领域（医疗/法律/代码），积累领域知识
4. **RLHF方向**：需要本科以上学历+领域专长，通过平台考核
5. **管理方向**：从标注员→质检→项目经理→运营总监

### 技能要求

- **基础**：细心耐心、基本电脑操作、中文/英文读写
- **进阶**：标注工具使用、质量管控、数据分析
- **高级**：AI/ML基础知识、Prompt Engineering、领域专业知识
- **管理**：项目管理、团队培训、客户关系、数据安全合规

### 职业发展路径

```
标注员 → 高级标注员 → 质检员 → 项目组长 → 项目经理 → 运营总监
                ↓
        领域专家(医疗/法律/代码) → RLHF专家 → AI训练师
                ↓
        标注工具开发 → 数据工程师 → AI工程师
```

## 行业趋势

1. **从量到质**：大模型时代更需要高质量专家标注，而非海量廉价劳动力
2. **RLHF主导**：人类偏好对齐成为核心需求，单价提升3-10倍
3. **AI辅助标注**：预标注+人工修正成为主流，纯人工标注减少
4. **合规要求提升**：数据隐私(GDPR/个保法)、标注员权益保障受关注
5. **代码/推理标注爆发**：数学推理、代码生成评估成为最高价值标注类型
6. **合成数据补充**：部分场景被合成数据替代，但人类验证仍不可或缺
