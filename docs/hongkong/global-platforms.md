## 7. 怎么组合使用

| 目标 | 优先平台 | 原因 |
| --- | --- | --- |
| 发现岗位/雇主 | LinkedIn | 量最大、更新快、可按关键词+地点 |
| 看 HKD 月薪/合同 | Randstad、jobs.gov.hk | 薪资字段较常见；政府岗位透明 |
| 金融高阶岗位 | eFinancialCareers、LinkedIn | 银行/基金/交易岗位集中 |
| 初创/Web3 | Wellfound、LinkedIn | 早期团队、股权、远程/混合 |
| 本地中小企业 | JobsDB、CTgoodjobs（暂不可抓） | 目前最大盲区；需手动查或合法 API |
| 公司评价/薪资交叉验证 | Glassdoor（暂不可用）、Hays/Robert Walters 薪酬指南 | 需手动访问或后续接入 |

**建议动作**：

1. LinkedIn 设置 5–8 个关键词的 Job Alert（DevOps、SRE、Platform、Cloud、AI/ML、IT Support）；
2. 每周固定看 Randstad、eFinancialCareers、jobs.gov.hk 的新增；
3. 对 Wellfound 只筛香港/remote-friendly、能接受股权与早期风险的岗位；
4. 对猎头广告问清 end client、合同类型、HKD 月薪/年包、签证担保；
5. JobsDB/CTgoodjobs 用浏览器手动查，或等合法 API/合作渠道。

## 8. 口径与限制

- Wellfound 薪资为 USD/年 + equity，不能与 HKD 月薪直接比较；

- 所有平台均未绕过登录/验证码；不可访问的平台明确标注。
