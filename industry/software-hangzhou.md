# 杭州软件企业清单

## 1. 主题介绍
杭州以滨江、未来科技城、杭州软件园为核心承载区，依托阿里巴巴生态外溢和浙江民营金融的雄厚基础，形成了金融证券软件、税务软件、智慧安防与可视化软件、网络与基础软件的特色集群。恒生电子是证券基金核心交易系统的全国龙头，税友股份垄断国内涉税软件服务市场，新华三在企业网/路由器/云基础软件领域与华为分庭抗礼；信雅达、浙大网新、海康威视的软件业务、鸿合科技的教育互动软件共同构成"金融 + 税务 + 安防 + 教育 + 网络"的多元软件版图。杭州软件业以"金融科技软件 + 行业龙头软件"为标签，是长三角 To B 软件的重要支柱。
