# 需求说明 · agentic-newbee v0

## 1. 语料库需求

四类语料，全部 Markdown + frontmatter（title / category / tags / updated）：

| 类别 | 目录 | 内容 | v0 数量 |
| --- | --- | --- | --- |
| prompts | corpus/prompts/ | 可复用提示词模板，每篇含"何时用 / 模板 / 变量说明" | 4 |
| workflows | corpus/workflows/ | 完整工作流：步骤 + 判据 + 常见坑 | 3 |
| transcripts | corpus/transcripts/ | 示例对话节选与复盘（教学用，明确标注非真实日志） | 2 |
| checklists | corpus/checklists/ | 动作前检查清单 | 2 |

**质量红线**：

- 每篇必须有真实可用内容，禁止占位符与"TBD"（newbee 教训）。
- 每篇 frontmatter 必填 `title / category / tags / updated`。
- 单篇正文 30–120 行，超了就拆。
- 站内链接用相对路径，由校验脚本检查可达性。

## 2. Skills 库需求

- 格式：`skills/<name>/SKILL.md`，frontmatter 含 `name`（kebab-case）与 `description`（何时用，第三人称），正文为 agent 可直接执行的指令。
- v0 六个技能：repo-exploration、task-decomposition、tdd-with-agent、git-hygiene、systematic-debugging、reviewing-agent-output。
- description 必须让 agent 能判断"何时该装载本技能"。

## 3. Web App 需求

**页面**：

1. 首页：项目介绍、三件套导航、快速开始。
2. 语料库列表：按分类分组，标题 / 标签 / 摘要，支持客户端关键字过滤。
3. 语料详情：渲染 Markdown（标题层级、代码块、列表、表格、站内链接）。
4. Skills 列表：卡片（name / description）+ 过滤。
5. Skills 详情：渲染 SKILL.md。

**行为**：

- 内容在构建期经 `import.meta.glob` 以 raw 形式打进 bundle，运行时零网络请求（首屏 HTML/CSS/JS 之外）。
- 未知路由回退首页；站内链接在详情页内可点。
- 中文阅读体验：系统中文字体栈、代码块等宽字体、舒适行高。

**非目标**：无后端 API、无搜索索引服务、无用户系统、无编辑功能。

## 4. 工程需求

- TypeScript strict；`npm run build`（tsc + vite build）零错误。
- 语料完整性校验脚本 `npm run corpus:check`：frontmatter 必填项、站内链接可达、正文行数红线。
- git：合格 .gitignore（node_modules / dist / .DS_Store），初始提交干净，不含密钥与产物。

## 5. 验收标准

1. `npm --prefix webapp run build` 通过，产物为纯静态文件。
2. `npm --prefix webapp run corpus:check` 全绿（frontmatter / 链接 / 行数）。
3. dev server 下五个页面均可访问，列表过滤与详情渲染正常。
4. 语料与 skills 每篇都有实质内容，无占位符。
