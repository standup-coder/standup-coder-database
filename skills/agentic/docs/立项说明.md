## 1. 背景与动机

newbee 项目（2013 立项）停滞 11 年，复盘出三条教训：文档空壳化、整包引入改不动的第三方底座、git 卫生缺失（见[现状评估](现状评估-2026-09-29.md)）。

与此同时，"新人如何入门 agentic coding"这件事本身缺一套系统资料：提示词怎么写、流程怎么走、和 agent 的协作会话长什么样、哪些坑要提前避开。这些知识目前散落在个人经验和零散文章里，没有一个"新人可直接跟着做"的语料库。

## 2. 项目定位

**做什么**：为 agentic coding 新人提供三件套——

1. **语料库（corpus/）**：真实可复用的 prompts、workflows、示例对话复盘、checklists。Markdown 是唯一真值。
2. **Skills 库（skills/）**：标准 SKILL.md 格式的协作技能，agent 可直接装载执行（区别于 [skills-database](../../skills-database) 的岗位胜任力资料——那边回答"学什么技能"，这边回答"怎么和 agent 一起干活"）。
3. **Web App（webapp/）**：浏览与检索语料和 skills 的零后端站点，构建时把 MD 打进 bundle。

**不做什么（v0 非目标）**：无后端、无账号、无在线编辑、无评论系统；不做全文搜索引擎（客户端文本过滤够用）；不收录 agent runtime 之外的通用职场技能。

## 3. 与既有项目的关系

- **newbee**：精神续作。继承"帮新人"的定位，抛弃死代码与空文档的做法。
- **skills-database**：互补不重叠。该库是岗位胜任力（job competencies）的本地资料库；本项目是 agentic 协作技能与语料。

## 4. 技术选型

| 决策 | 选择 | 理由 | 放弃的替代 |
| --- | --- | --- | --- |
| 语料格式 | Markdown + frontmatter | 唯一真值，agent 与人都能直接读 | 数据库、Notion |
| Web 框架 | Vite 7 + React 19 + TypeScript | 主流、新人友好、构建时 `import.meta.glob` 载入 MD 零后端 | Next.js（无 SSR 需求，依赖重）、Astro（多一层范式） |
| Markdown 渲染 | marked | 单一轻依赖、零配置 | markdown-it（略重）、自研（易错） |
| 路由 | react-router-dom v7 | 事实标准 | 自写 hash 路由（不可维护） |
| 样式 | 手写 CSS（CSS 变量） | 依赖数控制到个位数，样式即文档 | Tailwind（构建链多一环） |
| 部署形态 | 静态站（`vite build`） | 零运维，GitHub Pages / 任意静态托管 | Node 服务 |

依赖数（运行时）：react、react-dom、react-router-dom、marked —— 共 4 个。

## 5. 里程碑

- **v0（本次交付）**：语料库首批 11 篇 + skills 首批 6 个 + Web App（首页 / 语料浏览 / skills 浏览 / 详情页 / 检索）+ 完整立项与需求文档 + 语料完整性校验脚本。
- **v1（候选）**：语料扩充（真实会话复盘投稿流程）、skills 触发场景实测、部署到静态托管。
- **v2（候选）**：个人学习进度标记（参照 skills-database 的 personal/ 模式）。
