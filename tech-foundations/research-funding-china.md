# 中国科研基金与科技计划清单

## 1. 概述

本清单系统梳理中国从国家级到省市级、从政府到企业社会的主要科研基金与科技计划，为科研人员、高校教师、企业研发部门提供全面的申报参考。涵盖基础研究、应用研究、技术攻关、成果转化等全链条资助体系。

## 2. 国家级科研基金与科技计划

### 2.1 国家自然科学基金（NSFC）

国家自然科学基金委员会设立，是中国基础研究最主要的资助渠道。

| 项目类型 | 资助额度 | 申报时间 | 适用对象 | 备注 |
|---------|---------|---------|---------|------|

| 青年科学基金 | 30万元/3年 | 每年3月 | 35岁以下（男性）/40岁以下（女性）博士 | 仅限一次 |
| 重点项目 | 250-350万元/5年 | 每年3月 | 具有高级专业技术职称人员 | 需前期积累 |
| 杰出青年科学基金 | 400万元/5年 | 每年4月 | 45岁以下优秀学者 | 竞争极激烈 |

## 6. 申报实务指南

### 6.1 年度申报时间线

| 时间段 | 主要申报事项 |
|-------|------------|
| 1-2月 | 国家自然科学基金指南发布、准备申请书 |
| 3月 | NSFC集中申报（面上/青年/重点） |
| 4月 | NSFC杰青/优青申报；国家重点研发计划指南发布 |
| 5-6月 | 重点研发计划项目申报；各省市基金申报 |
| 7-8月 | 企业基金申报（腾讯犀牛鸟等）；博士后基金第一批 |
| 9-10月 | 各部委专项申报；省市科技计划第二批 |
| 11-12月 | 博士后基金第二批；年度结题验收集中期 |

### 6.2 申请书撰写要点

- **选题**：紧扣指南方向，突出科学问题的原创性和重要性
- **摘要**：400字内概括研究背景、目标、方法和预期成果
- **研究基础**：展示前期工作积累、代表性成果（论文/专利/项目）
- **技术路线**：逻辑清晰、方法可行、有创新点
- **团队组成**：体现互补性，明确分工
- **预算编制**：设备费、材料费、测试费、差旅费、劳务费、间接费用比例合理（间接费用一般不超过总经费的20%-30%）

### 6.3 结题验收要点

- 对照任务书考核指标逐项说明完成情况
- 标注经费使用明细，确保与预算一致
- 附代表性成果证明（论文、专利、获奖、人才培养）
- 提前准备财务审计报告（重点项目必须）
- 未达标指标需说明原因及后续计划
