# 中国开发者技术大会清单

## 1. 概述

本清单收录中国境内主要的开发者技术大会，涵盖综合技术、人工智能、云计算、开源、数据库、网络安全及行业峰会等多个领域，为技术从业者提供参会选择参考。

## 2. 综合技术大会

### 2.1 QCon全球软件开发大会（北京站）
- **主办方**：极客邦科技 / InfoQ中国
