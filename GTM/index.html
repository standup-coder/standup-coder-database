三步成版

不需要注册，不需要付费——clone 下来，字就是你的。

铸

铸字clone

把整副字库铸到你本地：三百余篇 Markdown、两张静态应用、一整个控制台，全部随仓库走。

$ git clone https://github.com/standup-coder/standup-coder-database.git
排

排字compose

直接读：任何 Markdown 双击即读，全库零依赖；或起控制台：仪表板、岗位、企业、榜单、数据分析一屏看全。

控制台路线：cd console && npm install && npm run dev

印

印成print

把任意一篇丢给你的 AI，让它按你的经历重新排字：改简历、做复盘、定规划。内容为 AI 辅助生成，印行之前请自行核验一遍。
