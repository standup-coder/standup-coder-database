# 开发者关系工程师职位描述(JD)

## 岗位基本信息
- **岗位名称**：开发者关系工程师/开发者布道师(Developer Relations Engineer / Developer Advocate)
- **工作性质**：全职
- **工作地点**：北京/上海/深圳/杭州/远程
- **招聘人数**：若干
- **薪资范围**：25K-55K/月(根据经验水平)

## 岗位职责

### 开发者社区运营
- 建设和运营开发者社区(GitHub/Discord/论坛/微信群)
- 策划和组织线上/线下开发者活动(Meetup/Hackathon/Workshop)
- 维护开发者关系，建立核心开发者(KOL)网络
- 监控社区健康度指标(活跃度/留存率/贡献者增长)
- 建立开发者激励计划和贡献者成长体系

### 技术内容创作
- 撰写高质量技术博客、教程和最佳实践文档
- 制作技术视频(教程/Demo/技术解读)
- 编写SDK/API使用指南和Quick Start文档
- 产出技术白皮书和解决方案案例
- 维护技术Newsletter和定期内容推送

### 技术演讲与会议参与
- 在国内外技术大会进行演讲(QCon/ArchSummit/GopherChina/KubeCon)
- 组织和参与公司技术开放日活动
- 代表公司参与开源社区会议和标准制定
- 策划和主持技术直播和AMA活动
- 建立个人和公司技术品牌影响力

### 开发者反馈与产品改进
- 收集和分析开发者对产品的反馈和痛点
- 将开发者需求转化为产品改进建议
- 参与产品路线图讨论，代表开发者视角
- 跟踪竞品开发者体验，输出分析报告
- 建立开发者满意度调研和NPS追踪机制

### 开源项目推广与技术品牌建设
- 制定开源项目的推广策略和增长计划
- 管理GitHub仓库(Star增长/Issue响应/PR审核)
- 建设技术品牌(技术博客/社交媒体/开发者口碑)
- 与高校/培训机构建立技术教育合作
- 推动开发者生态合作伙伴关系建设

## 任职要求

### 必备技能
**技术能力**：
- 具备全栈开发能力，能独立完成Demo和示例项目

- 能快速学习和理解新技术产品并产出教程
- 具备代码审查和技术方案评估能力
- 了解SDK/API设计原则和开发者体验(DX)最佳实践

**内容与传播能力**：
- 优秀的中英文技术写作能力
- 具备公开演讲和技术分享能力(有演讲视频/博客优先)
- 熟悉技术内容营销方法论
- 能制作高质量技术视频和演示文稿
- 具备将复杂技术概念通俗化表达的能力

**社区运营能力**：
- 熟悉主流开发者社区运营(GitHub/Discord/掘金/SegmentFault/Stack Overflow)

- 有开发者关系维护和人脉建设能力
- 了解开发者增长(Growth)和留存策略

## 面试准备建议

### 高频面试题
1. **开发者体验(DX)**：如何评估和改善一个SDK/API的开发者体验？你会关注哪些指标？
2. **社区增长策略**：一个新建的开源项目如何从0到1000 Star？你的增长策略是什么？
3. **内容创作**：如何将一个复杂的技术概念转化为一篇易于理解的技术博客？
4. **开发者反馈闭环**：如何系统性地收集开发者反馈并推动产品改进？
5. **技术品牌**：如何为一个开发者工具产品建立技术品牌影响力？

### 实操考核题
- 为指定产品撰写一篇Quick Start教程(限时2小时)
- 录制一个5分钟的产品Demo视频
- 设计一场线上Hackathon活动方案
- 分析竞品开发者文档并给出改进建议

### 面试流程
1. **初步沟通**(HR电话)：30分钟基本情况了解
2. **技术评估**(代码/Demo)：全栈开发能力验证
3. **内容创作**(写作/演讲)：技术内容产出能力考核
4. **社区策略**(方案讨论)：开发者增长和运营方案
5. **文化匹配**(团队交流)：价值观和工作方式匹配
6. **发放Offer**：通过后1周内正式发出
